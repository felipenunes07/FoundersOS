## ✨ Recursos Principais

- 🧠 **Segundo Cérebro Centralizado**: Conecta notas do Obsidian, mensagens no Slack, transcrições de reuniões e documentos do negócio.
- ⚡ **Visuais Interativos e Canvas 3D**: Animações de cérebro orbital e estelar construídos em Three.js e HTML5 Canvas.
- 📈 **Gráficos de Crescimento Composto**: Visualização do efeito composto das decisões executivas geridas por IA.
- 🛠️ **Arquitetura em Camadas**: Camadas de percepção, memória de longo prazo, raciocínio e execução autônoma.
- 🎨 **Design Neumórfico & Dark Mode**: Interface moderna inspirada nos melhores softwares executivos do mercado.

## 🚀 Como Executar Localmente

### Pré-requisitos
Certifique-se de ter o **Node.js (v18+)** e **npm** instalados.

### 1. Clonar o repositório
```bash
git clone https://github.com/felipenunes07/FoundersOS.git
cd FoundersOS
```

### 2. Instalar dependências
```bash
npm install
```

### 3. Iniciar o servidor de desenvolvimento
```bash
npm run dev
```

Abra o navegador em `http://localhost:3001` (ou na porta configurada) para visualizar a aplicação!
